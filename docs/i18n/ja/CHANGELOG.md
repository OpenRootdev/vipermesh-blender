<a id="130---2026-10-07"></a>
## [1.3.0] - 2026-10-07

<a id="added"></a>
### 追加

- リポジトリと連携した GitHub Pages の紹介、設定手順、正確な機能上の制限。
- 画像を扱える MCP クライアント向けの、サイズ制限付き PNG/JPEG のインライン出力。
- 現在の Blender ツール群にすでに存在するジオメトリや変形の診断、保護付きアドオン操作を公開配布物に同期。

<a id="changed"></a>
### 変更

- 最終処理で既存のカメラや照明を保持し、blend ファイルを保存せずにレンダリングできるようになりました。名前付きの空間検証が失敗すると最終出力を停止し、修正情報を保持します。
- 固定されたプレビュー回数を廃止しました。ファイルの正常性を品質判定と見なさず、タスクに応じた視覚的な確認と未解決の不具合の開示を要求します。
- blend ファイルの保存を明示的にし、段階的な最終処理では既存の保存先を拒否します。
- 公開依存関係のロックと SDK の最低要件を更新しました。新規インストールの監査で問題は検出されていません。
- パッケージ検証で、同梱するすべてのスキル参考資料を確認するようになりました。
- バックアップやエクスポート失敗後のリターゲットのロールバック、不完全なインポートの後処理、キャンセルされたオペレーターの扱い、列挙型フラグの引数変換、実装を反映するアドオンのフィンガープリントを修正しました。Blender 実行時の回帰テストを追加しました。

<a id="changed-1"></a>
### 変更

- エクスポートされていた非公開のツールガイド資料を、簡潔でインストール可能な公開エージェントスキルと、状況に合わせて使える参考資料に置き換えました。
- ネイティブ stdio クライアントの設定を明示し、任意であり、まだサポートされていない Docker MCP Toolkit の経路を説明しました。
- 非公開の `data/tool-guides` の内容が公開リリースに入ることを防ぐエクスポート検査を追加しました。

<a id="120---2026-07-25"></a>
## [1.2.0] - 2026-07-25

<a id="added-1"></a>
### 追加

- エージェントのセッションごとに単一の直列化された Blender 接続を持つ、持続的な stdio MCP サーバー。
- Stopped、Ready、Agent connected、Error の状態を明示する Blender アドオン。
- 決定論的なシーン検査、組み立て、マテリアル、照明、カメラ、レンダリング、アニメーション、リギング、UV、エクスポート、リトポロジーのツール。
- 上限付きの一括呼び出しと、構築、プレビュー検査、最終処理の段階的な作業手順。
- セッションの初期設定、MCP リソース、簡潔な操作コンテキスト、新しいエージェント向けのリポジトリ内ガイダンス。
- 本当に独自の Blender 作業が必要な場合の、明示的な `execute_code` フォールバック。
- ローカル限定のループバック通信と公開リリースの検証。
